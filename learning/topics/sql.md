# SQL e dados

## Objetivo

Consultar e modificar dados relacionais com clareza e segurança.

## Conceitos essenciais

Tabela, linha, coluna, chaves, SELECT, WHERE, ORDER BY, JOIN, agregações, NULL, constraints e modelagem.

## Preciso conseguir explicar

O que uma consulta retorna e como um filtro afeta o resultado.

## Preciso conseguir implementar

SELECT com colunas explícitas e WHERE; depois JOIN e agregações.

## Erros comuns

Usar `SELECT *`; comparar NULL com `=`; interpolar valores externos na query.

## Exercícios relacionados

EX005, EX008.
