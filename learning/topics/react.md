# React

## Objetivo

Construir interfaces pequenas a partir de estado e componentes.

## Conceitos essenciais

Componentes, props, state, eventos, useState, useEffect, listas, key, condicionais e formulários.

## Preciso conseguir explicar

Fluxo de props e por que uma mudança de state renderiza novamente.

## Preciso conseguir implementar

Componente de lista e formulário controlado simples.

## Erros comuns

Mutar state; usar índice como key sem avaliar; efeitos com dependências erradas.
