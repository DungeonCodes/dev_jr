# Git e terminal

## Objetivo

Inspecionar mudanças e operar o repositório com segurança.

## Conceitos essenciais

status, diff, add, commit, log, branch, switch, merge, pull, push, conflitos e comandos de navegação.

## Preciso conseguir explicar

O estado do working tree, staging area e histórico.

## Preciso conseguir implementar

Criar branch, revisar diff e resolver conflito simples em ambiente seguro.

## Erros comuns

Commitar dados sensíveis; usar comandos destrutivos sem revisar alvo.
