# Next.js

## Objetivo

Compreender uma aplicação web introdutória com App Router.

## Conceitos essenciais

Page, layout, route handlers, Server/Client Components, params, searchParams, fetch e env.

## Preciso conseguir explicar

Diferença entre componente de servidor e cliente e o caminho de uma requisição.

## Preciso conseguir implementar

Página e route handler mínimos, com loading/erro quando aplicável.

## Erros comuns

Expor env privada no cliente; usar componente cliente sem necessidade.
