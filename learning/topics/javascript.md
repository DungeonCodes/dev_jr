# JavaScript

## Objetivo

Usar a linguagem para resolver problemas e ler código com segurança.

## Conceitos essenciais

Arrays, objetos, funções, escopo, map, filter, reduce, módulos, Promise, async/await e erros.

## Preciso conseguir explicar

Diferença entre transformação, filtro e redução; fluxo assíncrono e propagação de erro.

## Preciso conseguir implementar

Funções puras simples e chamadas assíncronas com tratamento adequado.

## Erros comuns

Esquecer `await`; usar método de array inadequado; confundir `null` e `undefined`.
