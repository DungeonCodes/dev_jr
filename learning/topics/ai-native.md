# AI-native

## Objetivo

Usar IA criticamente, sem terceirizar entendimento técnico.

## Conceitos essenciais

Leitura de código gerado, pressupostos, bugs, segurança, validação, testes, explicação e complexidade.

## Preciso conseguir explicar

O que o código faz, por que funciona ou falha, entradas, saídas, riscos e testes necessários.

## Preciso conseguir implementar

Revisão estruturada após tentativa, registrando `off`, `review` ou `assisted`.

## Erros comuns

Aceitar saída sem testar; não identificar SQL injection; usar IA antes de formular hipótese.
