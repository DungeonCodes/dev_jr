# HTTP e REST

## Objetivo

Compreender a troca entre cliente e servidor e interpretar respostas.

## Conceitos essenciais

Request, response, JSON, headers, body, query/path params, métodos, status, fetch e erros.

## Preciso conseguir explicar

Quando usar método, status e corpo adequados; diferença entre falha do cliente e servidor.

## Preciso conseguir implementar

Classificação de status e consumo assíncrono básico.

## Erros comuns

Tratar todo 2xx/3xx como igual; esquecer JSON assíncrono; não validar response.

EX004, EX007, EX008.
