# Roadmap de aprendizagem

O ciclo é sempre **conceito → exercícios → revisão**. Cursos são apoio, não pré-requisito: após estudar `if` e `else`, pratique condição, debugging e explicação antes de avançar.

## Fase 0 — Diagnóstico

Objetivo: descobrir lacunas cedo em lógica, JavaScript, HTTP, SQL, leitura de código e debugging. Faça-o após o Sprint 0, sem esperar terminar cursos.

## Fase 1 — Fundamentos + JavaScript

Variáveis, tipos, operadores, `if/else`, loops, arrays, objetos, strings, funções, escopo, `map`, `filter`, `reduce` introdutório, leitura de código e debugging básico.

## Fase 2 — HTTP + APIs

Cliente, servidor, request, response, JSON, headers, body, query/path params, GET, POST, PUT, PATCH, DELETE, status HTTP, `fetch`, `async/await`, Promise e erros.

## Fase 3 — SQL + Dados

Banco relacional, tabela, linha, coluna, primary/foreign key, SELECT, FROM, WHERE, ORDER BY, GROUP BY, HAVING, JOIN, INSERT, UPDATE, DELETE, NULL, constraints, agregações, modelagem e índices conceituais.

## Fase 4 — TypeScript + Git

TypeScript: tipos, arrays, objetos, funções, interfaces, `type`, union, opcionais, narrowing e generics básicos. Git: status, diff, add, commit, log, branch, switch, merge, pull, push, conflitos simples e pull request conceitual.

## Fase 5 — React + Node + Next

React: componentes, props, state, eventos, hooks básicos, listas, keys, condicionais e formulários. Node: runtime, npm, módulos, env, assíncrono e APIs. Next: App Router, páginas, layout, route handlers, Server/Client Components, params, fetch e env.

## Fase 6 — Engenharia

Debugging, logs, erros, stack traces, testes unitários, mocks básicos, código testável, responsabilidades, leitura de código e code review.

## Fase 7 — Autenticação e segurança

Autenticação versus autorização, sessão, token, JWT, OAuth2, secrets, env e validação de entrada.

## Fase 8 — Python + Docker

Python: sintaxe, listas, dicionários, funções, classes básicas, exceptions, módulos, requests, async e FastAPI introdutório. Docker: imagem, container, Dockerfile, build, run, ps, volumes e Compose conceitual.

## Fase 9 — AI-native

Uso crítico de IA, leitura de código gerado, bugs, code review, validação, testes, explicação, pressupostos, segurança e complexidade desnecessária.

## Fase 10 — Simulados

Combinar lógica, JavaScript/TypeScript, SQL, HTTP, debugging, código de IA, pergunta oral e desafio prático.

## Após os simulados iniciais

Cloud, CI/CD e mensageria apenas em nível introdutório, conforme lacunas observadas. Kubernetes, microserviços e arquitetura distribuída avançada permanecem fora do escopo atual.

## Sprint 0

| Sessão | Revisão mínima | Próximo passo |
| --- | --- | --- |
| 1 | JavaScript: variáveis, tipos, operadores, `if/else` | condição + explicação |
| 2 | loops, arrays, objetos | EX001 e EX002 |
| 3 | funções, `map`, `filter` | EX001 + leitura de código |
| 4 | HTTP: request, response, GET, POST, JSON, status | EX004 |
| 5 | SQL: SELECT, FROM, WHERE, ORDER BY | EX005 |

Depois do Sprint 0: diagnóstico inicial.

## Ciclo inicial de 8 semanas

| Semana | Foco |
| --- | --- |
| 0 | Sprint 0 + diagnóstico |
| 1 | Lógica + JavaScript básico |
| 2 | Arrays + objetos + funções |
| 3 | Async + HTTP + APIs |
| 4 | SQL + modelagem |
| 5 | TypeScript + Git |
| 6 | React + Node + Next.js |
| 7 | Testing + auth + debugging |
| 8 | Python + Docker básico + AI-native + simulado |

Este cronograma é uma referência: o diagnóstico decide se deve acelerar, manter, repetir ou reforçar.
