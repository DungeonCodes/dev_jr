# Exercícios

Esta pasta receberá enunciados pequenos e tentativas do aluno. Cada exercício deve declarar entrada, saída esperada, critério de validação e perguntas de explicação técnica. Não há solução nesta infraestrutura inicial.

Use `AI_MODE=off` na primeira tentativa; `review` somente após executar e registrar o resultado; `assisted` quando usar ajuda durante a tentativa.
