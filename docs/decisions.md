# Decisions

## Registro

Data: 2026-09-03
Decisão: Usar TypeScript e Vitest como base inicial de execução.
Motivo: O repositório não possuía stack anterior; uma única ferramenta atende os primeiros exercícios JavaScript/TypeScript sem sobreposição.
Alternativas consideradas: Criar uma aplicação, múltiplos runners ou introduzir banco/Docker nesta fase.
Impacto esperado: Exercícios podem ser executados por ID ou categoria com dependências mínimas.

## Registro

Decisão: Adicionar `learning/` como camada documental ligada aos metadados existentes.
