# Master Context

## Objetivo Central

Estruturar um ambiente progressivo de treinamento para testes técnicos de Desenvolvedor / Software Engineer Júnior.

## Tipo de Projeto

Repositório local de treinamento prático, sem aplicação final nesta fase.

## Público, Usuários ou Stakeholders

Aluno em preparação para vagas Júnior Fullstack, Software Engineering e AI-Native.

## Problema a Resolver

Preparar prática organizada para resolução, leitura, explicação, debugging, teste e revisão crítica de código.

## Escopo Inicial

Estrutura de categorias, mecanismo único de testes, progresso, regras de IA e lote inicial de oito exercícios.

## Fora de Escopo

Aplicação web, dashboard, banco de dados para controle, autenticação do sistema, Docker obrigatório e lote amplo de exercícios.

## Entradas

Enunciados, implementações do aluno, testes, fixtures e registros de progresso.

## Saídas Esperadas

Feedback de testes, histórico de tentativas e preparação para simulados futuros.

## Restrições e Guardrails

Não revelar soluções antes da tentativa; separar referências; não sobrescrever respostas; não usar dados pessoais ou secrets.

## Premissas e Dependências

Node.js e npm locais para exercícios JavaScript/TypeScript. Python será acrescentado quando houver exercícios desse bloco.

## Critérios de Sucesso e Aceitação

Exercícios possuem enunciado, área de resposta, metadados e testes quando aplicável; referências são separadas; comandos documentados funcionam.

## Ponto de Partida

Repositório novo, sem commits, dependências ou ferramentas de teste anteriores.

## Próxima Instrução para o Agente

Após a revisão humana, iniciar os exercícios em ordem progressiva e registrar cada tentativa.
