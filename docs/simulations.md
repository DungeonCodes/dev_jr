# Simulados

`simulations/` está reservado para simulados futuros. Um simulado poderá combinar lógica, JavaScript/TypeScript, SQL, API, debugging, leitura de código, pergunta técnica e desafio prático.

Cada simulado deve registrar os IDs selecionados, tempo, resultado, pontos de explicação e modo de IA no progresso. Não há simulados preenchidos nesta fase.
